# Collection and folder pages

Overview, authorization, scripts, environments, and runs. Part of the [Restly spec](README.md).

## D24 Collection pages

Clicking a collection opens its overview with description, authorization, scripts, variables, and runs. Folders get overview, authorization, and scripts. The overview lists the requests with method, name, path, and folder (the Folder column is left out when no request is in a subfolder), and the meta line leaves out zero counts. A folder's Authorization sub-tab shows where its inherited auth comes from, as the request Auth tab does (D3). Runs shows an empty state with a Run collection button until the first run (2026-10-04). Clone copies the saved collection file with a new Postman id, so unsaved edits are saved first.
