Restly 0.3.1 has a redesigned interface, shows where a request's auth comes from, and adds a configurable history length, a User-Agent setting, and an error log.

The v0.3.0 tag was never released because its Linux build failed on a timing-dependent test, so this release includes everything since 0.2.0.

Restly is a fast desktop API client that works directly on your Postman collections. Collections and environments stay as Postman v2.1 files in `~/Restly`, so they can live in git and still open in Postman. There is no account or cloud sync.

## First launch

These builds are not signed with an Apple or Windows certificate, so the system warns the first time.

- **macOS.** Open the DMG, drag Restly onto Applications, then run `xattr -dr com.apple.quarantine /Applications/Restly.app` once, or allow it under System Settings > Privacy & Security.
- **Windows.** In the SmartScreen dialog, choose More info > Run anyway. The installer adds WebView2 if it is missing.
- **Debian and Ubuntu.** `sudo apt install ./restly_0.3.1_amd64.deb` installs the GTK and WebKitGTK dependencies.

## What's new

- **Redesign.** The whole interface was reworked for a cleaner, more consistent look: quieter colors with one accent, a consistent type scale, and designed empty, error, and in-flight states on every page. Settings > Appearance > Density (Compact, Default, Comfortable) changes row and control heights.
- **Window and tabs.** On macOS the top bar is 40 px with compact traffic lights. Tabs show an icon for their kind, keep a readable width, and scroll when there are many. A status bar shows the collection, save state, proxy mode, and cookie count.
- **Start page.** New tabs open on a start page with the common actions, recent requests, and their shortcuts. Shortcut hints show one keycap per key throughout the app.
- **Auth.** The Auth tab says where an inherited auth comes from, for example "Uses the auth from Northwind API collection: Bearer token". API key auth chooses Header or Query params with a toggle, and secret fields have a show button.
- **Body and scripts.** The File body has a file picker, GraphQL shows the query and variables side by side, and script editors fill the pane and offer common snippets.
- **Key-value tables.** Add a row by typing in the empty last row. Params, headers, and variables have a Description column and a Bulk edit mode.
- **Collection and folder pages.** Overview, Authorization, Scripts, Environments, and Runs were redesigned. Settings > Keyboard lists and filters every shortcut.
- **History length.** Settings > General sets how many sends are kept. The default is now 50, and lowering it deletes the oldest entries.
- **User-Agent.** Settings > Network sets the User-Agent sent when a request has none of its own, for sends, collection runs, WebSockets, and code snippets.
- **Error log.** Errors are written to `restly.log` in the data folder, which you can share when reporting a problem. Settings and the error screen have a Show log file button.

## Known limitations

- Scripts run in goja, not V8. `for await`, async generators, and `require` of anything but `chai` and `crypto-js` are not supported.
- Auth types other than basic, bearer, and API key are kept in the file but not applied. OAuth 2 token flows are not implemented.
- Client certificates must be PEM files without a passphrase.
- There are no builds for arm64 Windows or Linux yet.
