Restly 0.2.0 runs more imported Postman scripts unchanged, adds a find widget and auto-save, and lets you cancel a request while it is in flight.

Restly is a fast desktop API client that works directly on your Postman collections. Collections and environments stay as Postman v2.1 files in `~/Restly`, so they can live in git and still open in Postman. There is no account or cloud sync.

## First launch

These builds are not signed with an Apple or Windows certificate, so the system warns the first time.

- **macOS.** Open the DMG, drag Restly onto Applications, then run `xattr -dr com.apple.quarantine /Applications/Restly.app` once, or allow it under System Settings > Privacy & Security.
- **Windows.** In the SmartScreen dialog, choose More info > Run anyway. The installer adds WebView2 if it is missing.
- **Debian and Ubuntu.** `sudo apt install ./restly_0.2.0_amd64.deb` installs the GTK and WebKitGTK dependencies.

## What's new

- **Postman script compatibility.** `CryptoJS` is available as a global and through `require("crypto-js")`, so login scripts that hash with `CryptoJS.SHA256` run unchanged. `pm.request.addHeader`, `upsertHeader`, and `removeHeader` work. The script object is also available as `restly`, and the script editor autocompletes its members.
- **Cancel a request.** While a request is in flight, the Send button becomes Cancel, which stops its scripts and the HTTP exchange.
- **Find.** Cmd+F or Ctrl+F opens a find widget like VS Code's in the request body, scripts, and response, with match case, whole word, and regular expression options, a match count, and replace in editable editors.
- **Auto-save.** Collections and environments with unsaved changes save every 5 seconds. Settings > General turns it off or changes the interval.
- **Settings** has a section list, with General first.
- **Looks.** The dark theme is lighter and its dividers are visible, key-value tables are drawn as a grid, and editors highlight the current line.
- **Documentation.** [`docs/variables-and-scripts.md`](https://github.com/jsjain/restly/blob/v0.2.0/docs/variables-and-scripts.md) lists every variable scope, dynamic variable, and script API with examples.

## Known limitations

- Scripts run in goja, not V8. `for await`, async generators, and `require` of anything but `chai` and `crypto-js` are not supported.
- Auth types other than basic, bearer, and API key are kept in the file but not applied. OAuth 2 token flows are not implemented.
- Client certificates must be PEM files without a passphrase.
- There are no builds for arm64 Windows or Linux yet.
