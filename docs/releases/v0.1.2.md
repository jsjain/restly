Restly 0.1.2 ships the macOS downloads as DMG disk images instead of zips. Open one and drag Restly onto Applications. The app itself is unchanged from 0.1.0.

Restly is a fast desktop API client that works directly on your Postman collections. Collections and environments stay as Postman v2.1 files in `~/Restly`, so they can live in git and still open in Postman. There is no account or cloud sync.

## Downloads

| System | File |
| --- | --- |
| macOS 12 or newer, Apple silicon (M1 or later) | `Restly-0.1.2-macos-apple-silicon.dmg` |
| macOS 12 or newer, Intel | `Restly-0.1.2-macos-intel.dmg` |
| macOS 12 or newer, either kind of Mac | `Restly-0.1.2-macos-universal.dmg` |
| Windows 10 or 11, 64-bit | `Restly-0.1.2-windows-amd64-setup.exe` (installer) or `Restly-0.1.2-windows-amd64-portable.exe` |
| Ubuntu 24.04, Debian 13, or newer | `restly_0.1.2_amd64.deb` |
| Other Linux x86-64 with glibc 2.39 or newer | `Restly-0.1.2-linux-amd64.tar.gz` (needs GTK 3 and WebKitGTK 4.1) |

The Apple silicon, Intel, and universal apps run at the same speed. The universal app holds both versions and macOS runs the one that matches the Mac, so it is simply a larger download. `SHA256SUMS.txt` lists the checksum of every file.

## First launch

These builds are not signed with an Apple or Windows certificate, so the system warns the first time.

- **macOS.** Open the DMG, drag Restly onto Applications, then run `xattr -dr com.apple.quarantine /Applications/Restly.app` once, or allow it under System Settings > Privacy & Security.
- **Windows.** In the SmartScreen dialog, choose More info > Run anyway. The installer adds WebView2 if it is missing.
- **Debian and Ubuntu.** `sudo apt install ./restly_0.1.2_amd64.deb` installs the GTK and WebKitGTK dependencies.

## What's included

- **Requests.** Params, headers, raw JSON, XML, and text bodies with formatting, URL-encoded and form-data bodies with files, binary files, and GraphQL. Basic, bearer, and API key auth, inherited from folders and collections.
- **Responses.** Body, headers, cookies, test results, console output, and timings.
- **Variables and environments.** Local, data, environment, collection, and global scopes, and the `$guid`, `$timestamp`, `$isoTimestamp`, and `$randomInt` dynamic variables. Variables are colored by whether they resolve, show their value on hover, and autocomplete. Secrets are masked, and environments can be shared or belong to one collection.
- **Scripts.** Pre-request and test scripts at collection, folder, and request level, with the `pm` API, Chai assertions, and `pm.sendRequest`.
- **Collection runner.** Iterations, delay, `setNextRequest`, and results streamed per request.
- **Code generation.** cURL, JavaScript fetch, Python requests, and Go, in a live side panel.
- **cURL import.** Paste a cURL command into the URL bar or the import dialog.
- **WebSocket requests**, request **history**, and a **cookie** manager.
- **Network settings.** Proxy with a bypass list, TLS verification toggle, extra CA certificates, and per-host client certificates.
- **Keyboard.** A command palette, quick open for requests and environments, a keyboard-navigable collection tree, and shortcuts you can remap in `keybindings.json`. The defaults are in [`keybindings.default.json`](https://github.com/jsjain/restly/blob/v0.1.2/frontend/src/keybindings.default.json).
- **Themes.** Dark, Light, and One Dark built in, any VS Code color theme can be imported, and UI and editor fonts are configurable.

## Known limitations

- Scripts run in goja, not V8. `for await`, async generators, and `require` of anything but `chai` are not supported.
- Auth types other than basic, bearer, and API key are kept in the file but not applied. OAuth 2 token flows are not implemented.
- Client certificates must be PEM files without a passphrase.
- There are no builds for arm64 Windows or Linux yet.
