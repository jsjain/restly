Restly 0.3.3 can update itself, lets a long header list scroll, formats an imported cURL body, and suggests header names and values as you type.

Restly is a fast desktop API client that works directly on your Postman collections. Collections and environments stay as Postman v2.1 files in `~/Restly`, so they can live in git and still open in Postman. There is no account or cloud sync.

## First launch

These builds are not signed with an Apple or Windows certificate, so the system warns the first time.

- **macOS.** Open the DMG, drag Restly onto Applications, then run `xattr -dr com.apple.quarantine /Applications/Restly.app` once, or allow it under System Settings > Privacy & Security.
- **Windows.** In the SmartScreen dialog, choose More info > Run anyway. The installer adds WebView2 if it is missing.
- **Debian and Ubuntu.** `sudo apt install ./restly_0.3.3_amd64.deb` installs the GTK and WebKitGTK dependencies.

## What's new

- **Updates from inside Restly.** Restly checks GitHub for a new version at launch and once a day, and says so in a banner under the tab bar. Settings > General > Updates chooses what happens: Off, Notify me (the default), Download and ask to restart, or Install automatically (installs when you quit). Settings > About has a Check for updates button. On macOS and Windows, and for the Linux tar.gz, Restly replaces itself. The .deb build only shows the notice, because installing it needs root. This works from 0.3.3 on, so this one update is still a manual download.
- **Header suggestions.** In the Headers tab of HTTP and WebSocket requests, typing a Key suggests well-known header names such as Content-Type and Authorization, and typing a Value suggests common values for Content-Type, Accept, Accept-Encoding, Cache-Control, Connection and X-Requested-With. Arrow keys pick one and Tab or Enter accepts it.
- **Formatted cURL bodies.** A JSON body imported from a cURL command is indented, as if Format had been pressed. A body that formatting would change beyond whitespace, such as one with a very large integer, is kept as it was.

## What's fixed

- **Long header lists.** The Headers tab, and URL-encoded and form-data bodies, now scroll when their rows don't fit, instead of cutting off the last rows.
- **Suggestion lists.** The variable suggestion list no longer has an empty strip on its left.

## Known limitations

- Scripts run in goja, not V8. `for await`, async generators, and `require` of anything but `chai` and `crypto-js` are not supported.
- Auth types other than basic, bearer, and API key are kept in the file but not applied. OAuth 2 token flows are not implemented.
- Client certificates must be PEM files without a passphrase.
- There are no builds for arm64 Windows or Linux yet.
