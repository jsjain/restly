While a request is in flight, Send becomes Cancel and shows Esc. A thin progress bar runs under the URL field (proposed).

The button stays in the same place and drops the filled style, so it reads as a way out and not as the next action. The bar confirms that something is running even when the response pane is hidden. Today Send already turns into Cancel, but there is no shortcut hint and no progress cue.

6
The response pane says "Sending request…" with a live timer (proposed).

The timer counts up in tabular numerals so the text does not shift. Today the pane keeps showing the previous response or the empty hint while the request runs.

7
The empty response keeps its prompt and adds a keycap.

It uses the same wording as today, "Send a request to see the response", with a send icon and the ⌘↵ keycap in place of the trailing hint text.

8
Failures use a tinted banner with actions (proposed).

The message names the address that failed. Retry resends the same request and "Check proxy settings" opens Settings. The "Request cancelled" note stays small and neutral, because cancelling is not an error. Today failures show a plain error banner at the top of the response with no actions.
