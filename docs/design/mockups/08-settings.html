1
A left rail with icons replaces the stacked form.

General, Appearance, Network, Keyboard and About each get an icon and the active page uses the same selected-row style as the sidebar. Today the same five sections exist but read as one long form with plain labels.

2
Theme cards are small previews, not swatches.

Each card draws a mini request screen from that theme's own colors, with a focus ring on the selected one and an x on imported themes. The current ThemePicker shows a single swatch, so you had to apply a theme to see it. The Light preview nests the light tokens, and One Dark and Tokyo Night would render their own token sets in the app.

3
Each setting is a row: label and help left, control right.

Hairlines separate rows and sections get a 15 px title. The interface and editor fonts keep their select and size input, now aligned on one right edge. The current FontPicker stacks the same fields without help text. Importing a theme sits under the cards and reports any color adjusted for contrast.

4
Density control (proposed).

Compact, Default and Comfortable change the row heights already defined as tokens. This does not exist in the app today.

5
Proxy is a radio group that reveals its fields.

Choosing Custom shows Proxy URL and Bypass in a tinted panel under the row, and None or Environment variables hide it. Today the two inputs sit in the same flow as everything else whatever the choice.

6
TLS verification and the CA bundle are single-line rows.

The verify checkbox becomes a switch, and the CA bundle is a file chip with Change and Remove buttons. The current file picker is a plain field with a separate browse button.

7
Client certificates use the shared hairline table.

Host, Certificate and Key columns, a trash icon on hover and a ghost row to add the next entry, the same pattern as the request parameters table.

8
One primary Save, pinned to the bottom, with its consequence stated.

The note "Saving reconnects open connections" replaces a surprise. General (not shown) holds a single row, Auto-save, with a switch and an "Every 5 seconds" input from 1 to 600. Keyboard keeps the Open Keybindings File button, and About keeps the version details and Copy.
