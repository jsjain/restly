1
Workspace header replaces the empty sidebar row.

The name opens a workspace menu (open folder, reveal in Finder). New and Import stay as icon buttons. Collections and History become quiet text tabs instead of a filled pill switch.

2
Method tags are smaller, muted and in a fixed column.

All methods share one lightness, so no color shouts. POST moves from neon #e5e510 to amber. DELETE and OPTIONS shorten to DEL and OPT so names align.

3
Tabs have a top accent and fill to the editor surface.

The active tab joins the page below it, as in VS Code. Unsaved tabs show a dot in place of the close button. Collection and environment tabs show a quiet COL or ENV label.

4
The environment picker shows state with a dot.

A green dot means an environment is active. A hollow dot means none is selected. Cookies and Settings become plain icons after a divider.

5
Request actions move to the breadcrumb row.

Save and Code become ghost buttons that show their shortcuts. The toolbar keeps one primary action, Send. It is the only filled button on screen.

6
One URL field.

The method sits inside the URL field instead of in a separate box. Query parts are dimmed and variables are tinted. Its 34 px height marks it as the main input.

7
Quieter key-value table.

It keeps the hairline grid you asked for. Checkboxes are neutral rather than blue, and the delete icon appears only on hover. A ghost row replaces the "+ Add" button, and a Description column and Bulk edit are added.

8
The response header is one line.

Sub-tabs sit on the left and the status, time and size on the right, in tabular numerals. The test count is colored by its result. "View [Pretty]" becomes a segmented control with a Preview option.

9
Hovering the time shows a timing breakdown.

This replaces the current plain tooltip with bars for DNS, connect, TLS, first byte and download. All the data already exists in httptrace.

10
New status bar (optional).

It shows the save state, proxy, cookie count and the palette hint. It gives auto-save a visible confirmation, since auto-save shows no toast on success.
