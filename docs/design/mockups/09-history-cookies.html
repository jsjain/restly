History groups use quiet labels with a ghost Clear.

2
Each row reads as method, path, status and time.

The path leads and the host is dimmed after it, the status is a colored tag with ERR for a connection failure, and the time is muted with tabular digits. WebSocket entries use the WS tag. Today the row shows a filled method badge and the URL as one string.

3
Clicking an entry opens an unsaved draft tab.

The tab reads "GET /api/users" with the dirty dot in place of the close button, so it is clear nothing is stored yet. This is the same editable draft the app opens now, without a visual cue.

4
The breadcrumb says "History draft" and offers Save to collection.

A ghost button in the request toolbar position, with its shortcut, replaces having to find Save in a menu. The rest of the request layout is the one from the request screen.

5
Cookies toolbar is one line of ghost buttons.

Filter by domain, Refresh, Add cookie and a danger Clear all. The armed state "Click again to clear all" shown as a red tag next to the button is proposed. Today the two-step Clear all changes the button label only.

6
One Flags column replaces three checkbox columns (proposed).

HttpOnly, Secure and HostOnly show as small tags only when set, so most rows are shorter and easier to scan. Each domain gets a header with its cookie count and its own hairline table. Value is mono and truncated, and Save and Delete appear on hover instead of on every row.

7
Add cookie is an inline row at the top of the group.

Name, value, path, expiry and the three flags are edited in place with the row tinted. The current form is a separate block above the tables with a domain field and three checkboxes.

8
The expiry picker is a compact popover.

Month navigation, a 7-column day grid with today outlined and the selected day filled, Hour and Minute inputs, a Session cookie option, and Now and Done buttons. It has the same fields as the current DateTimePicker with calmer styling.
