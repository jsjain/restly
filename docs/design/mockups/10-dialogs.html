1
The collection menu uses icons and groups.

Add request, Add WebSocket and Add folder come first, then Rename, Clone, Run and Export, with Delete last and in red. Run has no shortcut, so none is drawn. The old styling is plain text rows with heavy borders and no grouping.

2
The tab context menu shows shortcuts and separates close actions.

Close and Duplicate tab carry their keys, and the five close commands are kept apart from Duplicate, Copy URL and Reveal in sidebar. The current menu has the same commands with heavier borders.

3
Save request is one calm dialog with a single filled button.

The Name field has the focus ring, and Collection and Folder are selects with a small list. The Folder list indents Auth, Users and Orders under Collection root, and the Collection list ends with New collection…. Save shows ⌘↵ (proposed).

4
Import cURL pairs a mono textarea with two buttons.

Cancel is outlined and Import is the only filled button. It sits beside the Save dialog here to save space, but it opens on its own over the scrim. The current dialog fills both buttons.

5
Unsaved changes: Don't save leaves the primary pair alone.

"Don't save" is a ghost button on the far left so it is not hit by mistake, then Cancel and a primary Save. The old confirm fills every button, so the safe choice did not stand out.

6
Quit variant uses a danger style for the destructive choice.

"Quit anyway" gets a red tint, not a filled red block, and Cancel stays neutral. It states how many collections are affected.

7
The method select lists each method in its own color.

The current method is checked, Custom… sits below a separator, and the footer hint tells you to type g, p or d to pick. The old list is plain text.

8
Toasts stack at the bottom right with a dismiss x.

The error toast names the file and the reason, and the neutral one confirms an import with its count. Both use the overlay surface and a soft shadow instead of a colored fill.
